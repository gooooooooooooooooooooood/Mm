дроны над Москвой летают
Путин головой поник
ну и пусть его взрывают
это Путина двойник.
позабыто всё на свете
сердце замерло в груди
только дроны, только ветер и пожары впереди.
настоящий Путин спрятан
закупорен в бургерлаз
всё равно его достанут
этот Путин пидора....
взлетаяяяяя
как кометыыы
невееееедая преград
крылааааатые ракеты
летят в москвуууу
летяяяят.
